SilentDepth 開発タスク一覧

本書は GAME_SPEC.md と ROLE_SPEC.md、および AI_SPEC.md を実装タスクへ分解し、開発順にチェックできる形へ落とし込んだものです。

遊べるコア戦闘ループを先に作る 雰囲気演出はコア成立後に積み増す P1 - P2 - P3 の順に開発する

マイルストーン

  • M0: 役職UIと指揮系統UIが仕様に沿って安定表示される
  • M1: 平常時 -> 接敵 -> 潜航戦闘 -> 雷撃 -> 離脱 が1ミッションとして成立する
  • M2: Alarm! による急速潜航フェーズが成立する
  • M3: ドイツ語復唱とTTSで艦内演出が成立する
  • M4: 損傷、静粛潜航、爆雷回避で生残戦が成立する
  • M5: AIクルーとAI駆逐艦艦長でリプレイ性が成立する
  • M6: 戦略層を含むキャンペーン構造が成立する

優先度定義

  • P1: 最優先。ゲームの核
  • P2: 体験を深くする中核
  • P3: 拡張とリプレイ性

Phase 1: コア戦闘ループ 進行中

目的: 索敵 -> 接敵 -> 潜航戦闘 -> 雷撃 -> 離脱 を最低限遊べる形にする

P1 タスク

  • battlePhase を patrol / contact / submerged_combat / attack / egress で実装する
  • フェーズごとの遷移条件を明示する
  • 平常時の接触発見イベントを実装する
  • 視認とソナーの両方で敵発見できるようにする
  • 接触後に敵優位と自艦優位の分岐を入れる
  • 潜航戦闘中の基本ループを作る
  • ソナー報告から接敵情報が更新されるようにする
  • 航海長操作を戦術結果へ反映させる
  • 雷撃シーケンスを段階化する
  • 離脱フェーズへの遷移条件を実装する
  • 最低限の戦果判定を実装する

P2 タスク / 確認項目

  • ミッション開始条件を時刻 / 海象 / 初期位置 / 目標種別で持たせる
  • 接敵ごとに敵編成を変えられるようにする
  • フェーズ別のHUD文言を用意する
  • 浮上双眼鏡攻撃 の allowed / risky / blocked 判定を追加する
  • binocularExposureTimer を危険度へ反映する
  • 双眼鏡観測時の Speed / AOB 推定補助を高精度化する
  • 双眼鏡攻撃時の発射準備短縮と 即潜航 / 水上離脱 分岐を追加する
  • 護衛艦AIに双眼鏡浮上艦への高優先反応を追加する
  • プレイヤーが何も分からないまま詰まるフェーズがない
  • 雷撃後に離脱判断まで要求される

Phase 2: 急速潜航フェーズ 進行中

目的: Alarm! 発令から完全潜航までの30秒をゲームとして成立させる

P1 タスク

  • battlePhase に alarm_dive を追加する
  • Alarm! トリガーを実装する
  • 急速潜航専用UIを追加する
  • 30秒タイマーを追加する
  • 部署別タスク進行を状態として管理する
  • 急速潜航の主要アクションを個別タスク化する
  • 成否で被探知率、初期深度、損傷を補正する
  • 成功時と失敗時の分岐を作る

P2 タスク / 確認項目

  • 非番乗組員の前部移動を演出と数値効果の両方で表現する
  • 航海長の深度設定や潜舵操作が潜航時間へ効くようにする
  • 機関部の遅延や故障イベントを差し込める余地を作る
  • Alarm! は通常の深度変更より明確に別物として感じられる
  • 成否の違いがその後のプレイに残る

Phase 3: 音声復唱・艦内演出 進行中

目的: 艦内の命令と復唱を、見えるだけでなく聞こえるものにする

P1 タスク

  • ドイツ語復唱テンプレートテーブルをデータ化する
  • speakerRole / trigger / germanText / japaneseGloss / priority / voiceStyle の構造を定義する
  • 命令イベントから復唱イベントを発火させる
  • UIログにドイツ語原文と日本語意味を表示する
  • 音声ON/OFF設定を追加する
  • テキストのみでも成立するフォールバックを用意する

P2 / P3 タスク / 確認項目

  • speechSynthesis ベースのTTS再生を追加する
  • critical / high / normal の優先度キューを実装する
  • 同一話者クールダウンを実装する
  • Alarm! ベル、爆雷、機関音と音声のミックス方針を実装する
  • 話者別の話速や声質の設定項目を持たせる
  • ブラウザごとの de-DE 音声差分を吸収する
  • 音声入力による艦長命令の受け口を検討する
  • 重要命令は必ず復唱される
  • 音声を切ってもテキストだけでゲーム進行に困らない

Phase 4: 損傷・静粛潜航・回避 進行中

目的: 雷撃後の生残戦を、独立した緊張フェーズとして成立させる

P1 タスク

  • 損傷部位モデルを追加する
  • 浸水 / 電源 / 機関 / 発射管 / 操舵 などの系統損傷を分ける
  • silent_running フェーズを実装する
  • 騒音値が敵探知率に影響するようにする
  • 爆雷攻撃イベントを実装する
  • 回避行動の結果が被害量を左右するようにする
  • ビルジポンプや応急修理の優先度を持たせる

P2 タスク / 確認項目

  • 工具落下や移動音などの艦内ノイズ要素をイベント化する
  • 深深度への移行と圧壊リスクを導入する
  • 損傷が役職UIにどのような制限を与えるか設計する
  • 雷撃後の最適行動が毎回 即リセット ではなく生還判断になる
  • 静粛潜航が数値だけでなく体感として分かる

Phase 5: AIクルー / AI駆逐艦艦長 進行中

目的: 役職間連携と敵護衛の判断に変化を持たせ、毎回違う戦闘にする

P1 タスク

  • AI_SPEC.md を基準に AI領域と非AI領域の責務をコードへ切り分ける
  • 敵駆逐艦艦長AIの意思決定レイヤーを作る
  • escort_return / investigate_contact / attack_run / lost_contact_search / surface_pursuit を状態化する
  • 爆雷投下後の acousticJammingFactor を駆逐艦AIの追尾精度低下へ接続する
  • 接触喪失時に最終推定位置周辺の探索を行う捜索ロジックを追加する
  • クルーSOPベースの半自律行動を作る
  • 艦長命令に対して各部署が自動で一定範囲まで実行するようにする
  • 艦内復唱AIの最小版として Alarm! / 接触報告 / 発射準備完了 / 発射 / 損傷報告 をテンプレート化する
  • speakerRole / trigger / germanText / japaneseGloss / priority / voiceStyle 構造を実装する
  • 録音音声優先、未収録時はTTSまたはテキストへフォールバックする音声キューを実装する
  • ソナー員AIとして観測段階に応じた短報 / 詳報 / 艦種推定を生成する
  • 航海長AIとして推奨針路 / 推奨速力 / 推奨深度 / 理由を返す助言層を追加する
  • 雷撃士AIとして Speed推定補助 / AOB推定補助 / 発射不可理由 を返す説明層を追加する
  • 初心者アドバイザーAIとして次にやるべき行動を1行で出すヒント層を追加する

P2 / P3 タスク

  • 敵艦長に 慎重 aggressive 執拗 などの性格パラメータを持たせる
  • 性格差に応じて護衛復帰優先 / 攻撃走維持 / 接触喪失後の粘りを変化させる
  • 副長、機関長、ソナー員から短い提案を返す仕組みを追加する
  • 艦内クルーAIの文言ゆらぎを役職別制約つきで追加する
  • ソナー員AIの報告を内部観測段階へ接続する
  • 航海長AIの助言を Captain Notes / Captain Intent / Navigation Report に反映する
  • 雷撃士AIの説明を Best Shot と TDC補助 に反映する
  • AI提案とプレイヤー介入の優先関係を整理する
  • AI応答失敗時に固定テンプレートへ戻すフォールバックを実装する
  • 戦闘後レポートAIとして 艦長日誌 / 戦術レビュー / 失敗要因分析 を生成する
  • 生成AIを使う場合の対象を雰囲気テキスト、提案、敵艦長の可変判断補助に限定する
  • 基幹判定はルールベースで固定する
  • AI使用ログを残し、どの提案が採用されたか追跡できるようにする

確認項目

  • AIが勝手にゲームを解きすぎない
  • それでも毎回同じ手順にはならない
  • AIが出す情報はプレイヤーが知り得る範囲を超えない
  • 駆逐艦が最強追尾装置ではなく、見失いと再捜索の揺らぎを持つ
  • 録音 / TTS / テキストのみ のどの構成でも進行不能にならない

雷撃指揮分担 / 斉射運用拡張 計画済み

目的: 艦長席は 攻撃判断 / 発射形式 / 発射許可、雷撃席は 発射管運用 / 諸元入力 / 実発射 を担当し、単射 / 斉射(Faecherschuss) を既存TDCへ自然に接続する。

P1 タスク

  • state.torpedoSequence に captainDesignatedTargetId を追加する
  • state.torpedoSequence に captainFirePattern(single / salvo2 / salvo3) を追加する
  • state.torpedoSequence に captainFireAuthorized を追加する
  • state.torpedoSequence に tubeSelectMode(auto / manual) を追加する
  • state.torpedoSequence に selectedTubeIds / reservedTubeIds / plannedShotSolutions を追加する
  • 艦長席に 目標指定 / 単射 / 斉射2 / 斉射3 / 発射許可 / 許可解除 を追加する
  • 雷撃席に 自動選定 / 手動選定 / I / II / III / IV / V を追加する
  • 発射許可 がないと 発射 実行不可にする
  • 手動選定時は chooseTubeForContact() を通さず明示管を優先する
  • 管の 装填 / 準備中 / 発射済 / 再装填中 を雷撃HUDへ明示する

P2 タスク

  • computeSalvoSpread() を追加し、目標長と距離から散開角を算出する
  • 2 * atan(L / 2D) ベースの見込み角をゲーム内散開幅へ変換する
  • 解精度に応じた誤差余裕を散開角へ加算する
  • plannedShotSolutions[] を各発射管ごとに個別生成する
  • 各魚雷へ 視差補正 / 発射管オフセット / 魚雷初動 を個別適用する
  • 雷撃HUDで 単射 / 斉射 ごとの予測線色分けを行う
  • 艦長席でも 指定目標 / 発射形式 / 許可状態 を常時確認できるようにする

P3 タスク

  • 斉射2 と 斉射3 の本発射を実装する
  • 使用管の同時消費と再装填待ちを実装する
  • 同一目標への連続射で前回使用管を避けるロジックを追加する
  • 後部発射管を aft shot 条件時のみ自動候補へ入れる
  • ドイツ語復唱へ 単射用意 / 斉射用意 / 発射許可 / 管番号復唱 を追加する
  • マニュアルへ 艦長権限 / 雷撃席権限 / 斉射手順 を追記する

確認項目

  • 艦長席のコマンドが航海長や雷撃席の役割を食わない
  • 目標指定 -> 諸元入力 -> 発射許可 -> 発射 の責任分担が画面上で分かる
  • 単射時は現行の射撃感を壊さない
  • 斉射時は各魚雷が同一線ではなく、意図した散開角で分かれる
  • 手動管選択時に未装填管を誤発射しない
