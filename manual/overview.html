全体の遊び方

SilentDepth は 4 役職を切り替えながら遊ぶ U ボート戦術ゲームです。 1 回のプレイは、索敵 → 接敵 → 観測 → 雷撃 → 離脱 の流れで進みます。

まず最初に読むページ
マニュアル索引 全体の遊び方 艦長 ソナー 雷撃 航海長 ステージ / Campaign

ゲームの基本ループ

  1. 索敵 ソナーで接触を拾い、艦長が交戦方針を決める。
  2. 戦闘配置 艦長が攻撃決意か離脱決意を出し、全部署が同じ方針で動く。
  3. 接敵 航海長が推奨射点または推奨離脱点へ誘導する。
  4. 観測 潜望鏡か双眼鏡で目標を見て、距離・方位・艦種を確かめる。
  5. 雷撃 雷撃席で標的選定、TDC、発射準備、発射。
  6. 離脱 離脱決意、深深度退避、全速離脱で生還を狙う。

雷撃標的選定、TDC、発射準備、発射標的選定 → 諸元入力 → 発射準備 → 発射
航海長深度、針路、速力、射点接近0m / 5m / 15m / 60m / 140m / 230m の違い

新しく覚える HUD ルール

  • Grid Report は外部報告用です。艦内では方位・距離・針路で報告し、司令部記録や位置把握は海軍グリッドで見ます。
  • Battle Stations は通常監視 / 攻撃決意 / 離脱決意を全席で共有します。
  • Battery が LOW のときは、潜航中の推進力が足りません。浮上してディーゼル充電が必要です。

最初の1プレイでやること

おすすめ手順

  • Stage I / 雷撃訓練 で始める
  • 艦長席で 攻撃決意
  • ソナー席で接触を確認
  • 航海長席で推奨射点と推奨進路を確認
  • 15m へ上げる
  • 艦長席で 潜望鏡
  • 雷撃席で発射まで進める

失敗しやすい点

  • 深いまま潜望鏡を使おうとする
  • 距離測定せずに Historical で撃とうとする
  • 護衛が近いのに浮上双眼鏡を続ける
  • 雷撃後に離脱せず、その場に留まる
  • 潜航したまま電池 0 で速力を上げようとする
