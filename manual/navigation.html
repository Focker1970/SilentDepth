航海長マニュアル

航海長席は「どの深度で、どの針路で、どの速力なら有利か」を作る席です。射点形成と生残の両方を支えます。

マニュアル索引 全体の遊び方 艦長 ソナー 雷撃 航海長 ステージ / Campaign

深度帯の意味

深度状態できること注意
0m完全浮上双眼鏡、ディーゼル推進、充電最も見つかりやすい
5m半没浅い待機、即潜航しやすい充電も双眼鏡も不可
15m潜望鏡深度潜望鏡観測、潜航雷撃まだ被発見リスクあり
60m通常潜航接敵維持、聴音追尾視認不可
140m深深度回避護衛回避、離脱観測も雷撃も不向き
230m実用限界近く緊急回避圧力リスクが高い

基本操作

  • 停止 / 微速 / 巡航 / 全速 で速力変更
  • 浮上 / 半没 / 15m / 60m / 140m / 230m で深度変更
  • 左へ / 保持 / 右へ で針路調整
  • Navigation Plot で自艦提案進路、敵予測進路、射点を確認

覚え方

  1. 接敵中 まずは 60m / 微速 でソナー接触を維持。
  2. 観測前 射点が近づいたら 15m へ上げる。
  3. 浮上観測 安全時だけ 0m へ上げて双眼鏡を使う。
  4. 回避 危険なら 140m かそれ以上で離脱。
