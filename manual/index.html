SilentDepth Player Manual

プレイマニュアル

一般プレイヤー向けの操作ガイドです。まずは全体の流れを読み、そのあと 艦長、ソナー、雷撃、航海長 の 個別ページを必要な順に参照してください。

対象: 初回プレイ / 役職切替 / Historical / Campaign
マニュアル索引 全体の遊び方 艦長 ソナー 雷撃 航海長 ステージ / Campaign

おすすめの読み順

  1. 1. 全体の遊び方 フェーズの流れ、役職の切替、勝ち筋を確認する。
  2. 2. 艦長 まずは艦長席だけで、戦闘配置 / 攻撃決意 / 離脱決意 / 浮上 / Alarm! の意味を覚える。
  3. 3. ソナー 接触を維持し、航海長と雷撃に渡す情報の作り方を覚える。
  4. 4. 雷撃 潜望鏡観測、TDC、発射準備、発射の順を確認する。
  5. 5. 航海長 深度帯の違いと、射点へ入るための操艦を覚える。
