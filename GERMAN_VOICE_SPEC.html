SilentDepth German Voice Spec

ドイツ語音声実装仕様書

SilentDepth において、艦内命令復唱、アラーム、雷撃準備、接触報告を ドイツ語音声で再生するための実装仕様書。ブラウザ標準 TTS を基本とし、 将来的な録音音源・外部 TTS 置換も見据えた構成を前提にする。

対象: Web Speech API / de-DE / 復唱テンプレート / イベント再生 / フォールバック

目的

演出目的

  • Uボート艦内の緊張感を音声で補強する
  • 命令と復唱の関係をプレイヤーに体感させる
  • 役職ごとの雰囲気差を声色、速度、間で出す

ゲーム目的

  • 重要イベントを音で即時に伝える
  • HUD を見なくても状況判断しやすくする
  • 各部署の状態変化を音声レイヤーで補助する

実装方針

  1. 初期実装は speechSynthesis によるブラウザ標準 TTS を使用する
  2. 音声言語は基本 de-DE
  3. 各イベントは speakerRole, priority, germanText, rate, pitch を持つ
  4. 同時多発イベントはキューに積み、優先度順で再生する
  5. 将来は録音済み音声や外部 TTS に差し替え可能な抽象層を持つ

音声システム構成

必要コンポーネント

  • voiceEnabled: 音声再生トグル
  • voiceQueue: 復唱待ちキュー
  • voiceBusy: 再生中フラグ
  • lastVoiceAt: スパム抑制用の最終再生記録
  • selectedGermanVoice: 使用音声キャッシュ

再生ルール

  • 同一イベントの短時間連続発火は抑制する
  • critical は通常キューより優先して前へ積む
  • ソナー音が鳴っていても復唱が埋もれないよう音量設計する
  • 字幕テキストは常時 HUD / ログにも残す

ブラウザ実装要件

最低限必要な処理

  • speechSynthesis.getVoices() で de-DE を探索
  • 最初のユーザー操作後に音声初期化
  • イベント発生時に SpeechSynthesisUtterance を生成
  • 再生中とキュー状態を UI に反映

注意点

  • 環境によってドイツ語音声の有無が違う
  • macOS / Safari / Chrome で音声名が異なる
  • 自動再生制限で初回無音になる可能性がある
  • TTS 品質は OS 依存で、軍艦的迫力は限定的

フォールバック方針

  1. de-DE 音声が見つかる場合: ドイツ語 TTS で再生
  2. ドイツ語音声がない場合: 同テキストを既定音声で再生、字幕に DE 表示
  3. TTS 自体が使えない場合: 音声再生を無効化し、ログと字幕のみ表示
  4. 将来の高品質化: 事前収録音声または外部 TTS に差し替え

ベル音の扱い

Alarm 演出

  • Alarm! Tauchen! の直前にベル音を 1 回以上鳴らす
  • ベル音は TTS ではなく短い効果音で扱う
  • ベル音終了前に復唱を重ねてもよいが、音量バランスを取る

実装案

  • 軽量: OscillatorNode で簡易ベル音生成
  • 標準: 小さな .mp3 / .wav を同梱
  • 優先順位は ベル音 → 艦長命令 → 各部署復唱

将来拡張

  • 役職ごとに別ボイスを割り当てる
  • AI 艦長の判断文もドイツ語で生成し、短文化して読み上げる
  • 駆逐艦側の英語音声通信を別レイヤーで混ぜる
  • 字幕パネルをつけて German / 日本語意図 を同時表示する
