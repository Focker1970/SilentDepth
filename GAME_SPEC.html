SilentDepth Game Specification

SilentDepth 全体ゲーム仕様

第二次世界大戦の北大西洋における Uボートのコンボイ戦を題材にした、役職切替型の戦術シミュレーションゲーム全体設計。 目的、ゲーム中タイムライン、フェーズ遷移、AI利用方針、実装計画までをまとめる。

対象: Uボート / 北大西洋 / コンボイ戦 / 急速潜航 / 潜航戦闘 / 雷撃 / 離脱

概要

SilentDepth は、第二次世界大戦の北大西洋における Uボートによる連合軍コンボイ戦を題材にした、役職切替型の戦術シミュレーションゲームである。

プレイヤーは単なる「潜水艦そのもの」ではなく、Uボート艦内の複数役職を切り替えながら、艦長として全体を指揮する。

  1. 指揮系統と部署連携
  2. 索敵 -> 接敵 -> 急速潜航 -> 潜航戦闘 -> 雷撃 -> 離脱 の緊張ある流れ
  3. 情報不足の中での判断

ゲームの目的

プレイヤー目標

  • 北大西洋で連合軍コンボイを追跡する
  • 護衛駆逐艦に捕まる前に、重要輸送船・商船へ有効打を与える
  • 爆雷攻撃を生き延び、艦と乗組員を保ったまま離脱する

勝利 / 敗北

  • 勝利: 主要目標撃沈または戦果条件達成後、離脱海域へ到達
  • 敗北: 圧壊、浸水、機関不能、急速潜航失敗、任務継続不能
  • 評価: 撃沈総トン数、損傷率、被探知回数、命中率、乗組員状態

コア体験

感じるべきこと

  • 艦長として命令を出す緊張感
  • 各部署の報告を統合して判断する感覚
  • ソナーだけを頼りに敵を追う不安
  • 雷撃解が成立した瞬間の快感
  • 爆雷回避中の静寂と圧迫感

デザイン主軸

自律型AIクルー + 手動介入型戦術シミュレーション

  • 平常時は各部署が半自律で動く
  • プレイヤーは命令と優先順位を決める
  • 緊急時や決定的局面のみ、直接役職切替して介入する
  • 雷撃だけは比較的ハードコアな演算と手順を要求する

プレイヤー役職

役職主な仕事ゲーム上の役割
艦長命令、観測、戦術判断、雷撃許可、急速潜航発令全体判断の中心
ソナー員受動聴音、能動ソナー、接触分類、方位報告外界情報の中心
雷撃士TDC入力、進角計算、発射管準備、発射攻撃の中心
航海長深度、針路、速力、トリム、離脱コース艦姿勢維持と操艦の中心

ゲーム中のタイムライン

  1. 平常時
  2. 索敵
  3. 敵艦発見
  4. 戦闘配備
  5. 急速潜航または接敵継続
  6. 潜航戦闘
  7. 雷撃
  8. 回避 / 静粛潜航
  9. 離脱
  10. 戦果判定

フェーズ詳細

1. 平常時

浮上中または通常航行中。見張り、哨戒、充電、補機管理が中心。

  • 速力変更、針路変更、深度指示
  • 双眼鏡監視、潜望鏡深度移行
  • AIクルーSOPの調整

2. 索敵

コンボイを捜索する段階。艦長とソナー員が主役。

  • どの深度で進むか
  • どれだけ静かに近づくか
  • 能動ソナーを使うか
  • 夜間水上接近を狙うか

3. 敵艦発見

視認または聴音で接触を得る局面。

  • プレイヤー優位なら戦闘配備へ
  • 敵優位なら Alarm! による急速潜航へ

4. 戦闘配備

平常時から戦闘シフトへ移る準備段階。

  • 艦長: 交戦方針決定
  • ソナー員: 方位追跡強化
  • 雷撃士: TDCと発射管準備
  • 航海長: 射点接近コース調整

5. 急速潜航

30秒前後の高密度手動フェーズ。

  • ハッチ閉鎖
  • ディーゼル停止
  • モーター切替
  • バラスト注水
  • 最大下げ角
  • 潜航完了

6. 潜航戦闘

潜航後の主戦闘フェーズ。ソナー主導で外界を把握する。

  • ソナー報告
  • 艦長判断
  • 航海長の針路・深度維持
  • 雷撃士の解構築

7. 雷撃

攻撃のクライマックス。

  • 標的選定
  • 距離・速度・AOB入力
  • 信管 / 深度 / 速度設定
  • 注水、同期、発射

8. 回避 / 静粛潜航

雷撃後または敵探知後の生残フェーズ。

  • 静粛潜航
  • 深深度への移行
  • 低速回避
  • 損傷制御

9. 離脱

雷撃成功後に生還を目指す。

  • 離脱針路維持
  • 護衛艦との距離確保
  • バッテリー / 損傷 / 深度管理

10. 戦果判定

  • 撃沈トン数
  • 重要輸送船撃沈の有無
  • 生還
  • 被害
  • 魚雷消費効率

AIの使い方

使うべき場所

  • 敵駆逐艦艦長: 捜索判断、護衛優先、爆雷投入、追尾方針
  • 艦内クルー: 命令復唱、定型報告、雰囲気演出
  • 副長 / 機関長 / ソナー員: 提案、SOPベースの半自律判断

使いすぎない方がいい場所

  • 基本操艦そのもの
  • 雷撃解そのものの最終決定
  • 深度や損傷の重要結果判定

実装方針

  • 最初から全部を再現しない
  • 遊べる戦闘ループ を先に作る
  • その後に急速潜航、復唱、損傷、群狼作戦を積み増す

現時点での推奨次アクション

  1. GAME_SPEC を基準に全体設計を固定する
  2. Alarm! フェーズを battlePhase として実装する
  3. ソナー、航海、雷撃を段階的ループへ接続する
  4. その後にドイツ語復唱とTTSを入れる

この順番なら、雰囲気だけ先行して中身が空になるのを避けつつ、Uボートらしさをしっかり積み上げられる。
