SilentDepth AI Specification

SilentDepth AI実装仕様

SilentDepth における AI 利用領域を定義し、敵艦の判断、艦内クルーの復唱と報告、 プレイヤー支援、戦闘後要約をどこまで AI に担わせるかを実装向けに整理した資料。

AI は物理計算の代替ではなく 判断・報告・演出・要約 の強化に使う

概要

目的は次の4点。

  1. 敵艦行動 を単純追尾ではなく戦術判断として表現する
  2. 艦内クルー報告 を状況に応じた自然な情報伝達へ拡張する
  3. プレイヤー支援 を初心者補助とヒストリカル補助の両立として実装する
  4. AIに任せる領域 と 通常ロジックで固定すべき領域 を分離する

AI利用方針

原則

  • 毎フレーム処理 は AI に任せない
  • 命中判定 深度計算 速度計算 ソナー強度 は従来ロジックで保持する
  • AI は イベント発生時 報告生成時 行動選択時 に限定する
  • AI 出力は必ず ゲーム内部状態をもとにした制約付き出力 にする

AIを使う / 使わない領域

使うべき領域

  • 敵駆逐艦の戦術判断
  • 艦内クルーの命令復唱と状況報告
  • 航海長 / ソナー員 / 雷撃士の補助進言
  • 戦闘後のログ要約

使わない領域

  • 船体移動
  • 魚雷会敵
  • 爆雷沈降
  • バッテリー消耗
  • 観測段階ゲージの内部進行
  • TDC 数学処理

AIシステム構成

系統 名称 主用途 呼び出し頻度
敵AI Destroyer Tactical AI 駆逐艦の追跡 / 捜索 / 攻撃方針決定 数秒ごと
艦内AI Crew Voice AI 命令復唱、部署報告、状況通話 イベントごと
支援AI Tactical Advisor AI 航海長 / ソナー / 雷撃の助言生成 状況更新ごと
記録AI After Action AI 戦闘要約、艦長日誌、失敗理由整理 ミッション終了時

1. 敵駆逐艦AI仕様

目的 / 入力 / 出力

駆逐艦を 常時正解追尾する最強敵 ではなく、情報が不完全な中で判断する指揮官 として表現する。

入力

  • 自艦の最終探知情報
  • 受動聴音結果
  • 能動ソナー結果
  • 直前の爆雷投下結果
  • 味方輸送船団との距離
  • 自艦が浮上中か潜航中か
  • 昼夜 / 海象 / 爆雷ジャミング状態

出力

  • 行動モード
  • 次の目標針路
  • 次の目標速力
  • 爆雷投下可否
  • 能動探知可否

AI判断ルール / 実装方式

  • 爆雷投下後は acousticJammingFactor を考慮し、一定時間は追尾精度を落とす
  • 接触喪失時は正解位置へ向かわず、最終推定位置 周辺を探索する
  • 夜間の双眼鏡浮上攻撃は、距離と警戒度が低ければ見逃す可能性を持たせる
  • 護衛艦は単艦撃沈より 船団防護 を優先する
  • 1〜3秒ごとの更新で state.contacts[i].aiIntent を再計算する
  • 実際の移動は既存 updateContacts() ロジックで処理する
  • AI は intent と priority のみ返す
モード 概要 典型行動
escort_return 護衛配置へ戻る 船団付近を低速警戒
investigate_contact 断続接触の確認 最終探知方位へ接近
attack_run 攻撃走に入る 高速接近、爆雷投下
lost_contact_search 接触喪失後の捜索 扇形捜索、速度低下
surface_pursuit 浮上Uボートへの追撃 見失うまで水上追尾

2. 艦内クルーAI仕様

目的 / 対象役職 / 主用途

艦内の命令伝達を、単純な固定文ではなく 状況に即した復唱 として表現する。

対象役職

  • 艦長
  • 当直将校
  • ソナー員
  • 航海長
  • 雷撃士
  • 機関部
  • 見張り員

主用途

  • Alarm! 発令時のドイツ語復唱
  • 接触報告の自然文生成
  • 発射準備完了報告
  • 被害報告
  • 離脱時の簡易会話

入力 / 出力 / 実装方針

入力

  • 現在フェーズ
  • 担当役職
  • 直前命令
  • 接触情報
  • 射撃解の状態
  • 損傷状態
  • 音声モード recorded / tts

出力

  • 日本語内部タグ
  • ドイツ語表示テキスト
  • 音声再生キュー

実装方針

  • 基本は テンプレート + 変数埋め込み
  • AI は文言のゆらぎ生成と状況に応じた短文化に使う
  • 役職別に語彙制限を設け、史実感を崩さない
状況 役職 出力例
Alarm 発令 当直将校 Alarm! Tauchen!
ハッチ閉鎖完了 見張り員 Brueckenluke geschlossen!
ソナー接触 ソナー員 Geraeuschkontakt Steuerbord voraus.
発射準備完了 雷撃士 Rohr eins klar.

3. ソナー員AI仕様

目的 / 入力 / 出力

ソナー観測の内部値を、そのまま出すのではなく 観測段階に応じた報告 としてプレイヤーへ伝える。

入力

  • observedContacts
  • intelStage
  • 接触強度
  • 方位変化
  • 推定速度
  • 推定針路
  • 目標種別推定

出力

  • 短報
  • 詳報
  • 艦種推定
  • 信頼度

実装例

  • 方位 40度、微弱接触
  • 右舷前方、距離は遠い。低速商船らしい
  • 方位一定、速力 3 ノット前後、針路 010 度と推定
段階 AIが言ってよい情報
方位段階 方位のみ
距離段階 おおまかな距離帯
速度段階 遅い / 中速 / 高速、または kt 推定
針路段階 進行方位推定、艦種推定

4. 航海長AI仕様

目的 / 入力 / 出力

索敵から射点形成までの操艦を、プレイヤーに理解しやすい形で助言する。

入力

  • 自艦位置、深度、速力、針路
  • 敵推定位置、推定針路、推定速力
  • 現在の艦長意図
  • battlePhase
  • 潜望鏡深度維持状態

出力

  • 推奨針路
  • 推奨速力
  • 推奨深度
  • 理由テキスト
  • 射点形成中 / 回り込み不足 / 先手維持 / 離脱優先 の評価

AI助言ルール

  • ソナー接触のみの段階では 前方回り込み を優先
  • 潜望鏡観測が成立したら 射点安定 を優先
  • 護衛急接近時は 回避優先 に切替
  • 進言は短く、HUDに収まる長さへ制限する

5. 雷撃士AI仕様

目的 / 入力 / 出力

ヒストリカルモードでプレイヤーの計算負荷を完全自動化せず、不足要素の説明 と 補助推定 に限定して支援する。

入力

  • TDC 現在値
  • 目標選定中の接触
  • 潜望鏡観測ログ
  • ソナー推定
  • 現在の射点幾何

出力

  • Speed 推定補助
  • AOB 推定補助
  • 発射不可理由
  • 再入力不要 / 再準備必要

典型出力 / 注意点

  • 速度推定は 2.8kt、潜望鏡追尾 9 秒より算出
  • AOB 推定は +35、艦影の向きから低信頼
  • 進角不足。もう少し前方へ回り込む必要あり

命中可否の最終判定は既存ロジックで行い、AI はあくまで 説明役 にとどめる。

6. 初心者アドバイザーAI仕様

目的 / 対象モード / 出力形式

本作の複雑な流れを壊さずに、初心者が次に何をすべきかを理解しやすくする。

対象モード

  • easy
  • historical

出力形式

  • 1行アドバイス
  • 失敗理由の短文説明
  • 現在フェーズで必要な次アクション

例 / 実装制約

  • 次は潜望鏡で距離測定を実施
  • ソナー接触のみでは艦種断定不可
  • 同一目標なので再準備は不要

実装制約

  • 戦況を先読みしすぎない
  • まだプレイヤーが得ていない内部真値は明かさない

7. 戦闘後レポートAI仕様

目的 / 入力 / 出力

戦闘後の結果を、プレイヤーが理解しやすい戦闘詳報へ要約する。

入力

  • ミッション結果
  • 命中数
  • 被探知回数
  • 主要フェーズ遷移
  • 魚雷命中 / 失走理由
  • 爆雷被害

出力

  • 艦長日誌
  • 戦術レビュー
  • 失敗要因分析

例

  • 接敵は良好だったが、AOB 推定不足により初弾は会敵せず
  • 駆逐艦は爆雷後に接触を一時喪失しており、その間の離脱判断は適切

実装優先順位

Phase AI-1 / AI-2

  • AI-1: 艦内復唱 AI、アラーム / 雷撃 / 接触報告のテンプレート制御
  • AI-2: ソナー員 AI、航海長 AI、雷撃士補助 AI

Phase AI-3 / AI-4

  • AI-3: 駆逐艦戦術 AI、接触喪失後の捜索判断、爆雷後ジャミング考慮
  • AI-4: 戦闘後レポート AI、艦長日誌自動生成

実装上の注意 / 結論

実装上の注意

  • AIが出してよい情報は プレイヤーが現在知っている情報 に限定する
  • 史実感を優先し、現代的すぎる口調や説明を避ける
  • ドイツ語音声は 録音優先、AI はテキスト補助と TTS 補完を担当する
  • AI応答が失敗してもゲームが止まらないよう、固定テンプレートへフォールバックする

結論

SilentDepth における AI は、戦闘の答えを代わりに出す存在 ではなく、 不完全な情報の中での判断と報告を厚くする存在 として使うのが最適である。

最初に実装すべきは次の3つ。

  1. 艦内復唱AI
  2. ソナー / 航海長の助言AI
  3. 駆逐艦の戦術AI

この順で進めることで、ゲームの計算核を壊さずに体験密度を上げられる。
