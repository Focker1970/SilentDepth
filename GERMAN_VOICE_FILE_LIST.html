Recommended Voice File Names

推奨ファイル名一覧

収録・管理・実装のための推奨命名規則。基本は role_event_detail.mp3 形式で統一する。

命名規則

  • captain_*: 艦長
  • engine_*: 機関
  • helm_*: 操舵
  • watch_*: 見張り
  • sonar_*: ソナー
  • torpedo_*: 雷撃
  • damage_*: 損害報告
