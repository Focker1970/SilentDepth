潜望鏡・雷撃ユーザーズマニュアル

SilentDepth における潜望鏡観測と雷撃操作のための実用マニュアル。 画面の見方、基本操作、Historical モードでの運用、失敗しやすい点をまとめる。

対象: 潜望鏡 / 距離測定 / TDC / 発射準備 / Historical 雷撃

潜望鏡の役割

  • 目標を視認する
  • 方位を確認する
  • 艦種を仮定して距離を測る
  • TDC に距離データを渡す

雷撃の役割

  • 標的を選ぶ
  • TDC に諸元を入れる
  • 発射管処理を完了する
  • 適切な深度と射点で発射する

潜望鏡マニュアル

基本操作

  • 艦長席で 潜望鏡 を押す
  • A で左へ 10°
  • D で右へ 10°
  • V で通常監視へ戻る
  • UI ボタンでも左右回転と正面復帰が可能

画面で見る場所

  • 潜望鏡方位: 現在の絶対方位
  • 艦首基準: 艦首から左右へ何度振っているか
  • 焦点目標: 現在視野内で測距対象になっている艦
  • 目盛り: 測距レティクル読取値

潜望鏡の使い方

  1. 1. 潜望鏡深度に入る 発射を狙うなら基本は 10m - 20m の範囲に入る。 深すぎると潜望鏡視認も発射もできない。
  2. 2. 目標を視野に入れる A / D または左右ボタンで旋回し、目標を視野中央へ寄せる。 焦って振りすぎると見失いやすい。
  3. 3. 艦種を仮定する 商船、重要輸送船、駆逐艦 のいずれかを選ぶ。 これは測距計算に使う。
  4. 4. 目盛りを合わせる レティクルの見え方に合わせて −0.5 / +0.5 で読取値を調整する。 合わなくなったら リセット を使う。
  5. 5. 距離測定を行う 距離測定 を押すと測定結果が記録され、TDC へ距離同期できるようになる。

潜望鏡のコツ

うまく使うコツ

  • まずソナーで方位を把握してから潜望鏡を振る
  • 目標を中央付近に置いてから測距する
  • 護衛艦より輸送船を優先観測すると戦果に直結しやすい
  • 深度 15m 前後だと発射準備へつなぎやすい

失敗しやすい点

  • 深度が深すぎて視認できていない
  • 艦種未選択のまま測距しようとする
  • 測距せずに雷撃席へ行き、TDC 距離が空のまま止まる
  • 回しすぎて目標を視野外へ逃がす

雷撃マニュアル

雷撃席の主要 UI

  • 標的選定
  • 諸元入力
  • 発射準備
  • 発射
  • Torpedo Data Computer
  • Firing Sequence

重要な考え方

  • Easy より Historical のほうが厳格
  • 発射できるだけでなく、当たる条件も別にある
  • 視認、測距、TDC、深度維持が揃って初めて安定する

雷撃の操作手順

  1. 1. 標的を選定する 標的選定 を押すと、既知接触から最有力の目標が選ばれる。
  2. 2. TDC に方位を入れる ソナー同期 を押して Bearing を入れる。
  3. 3. TDC に距離を入れる 艦長席で測距後、潜望鏡同期 を押して Range を入れる。
  4. 4. Speed と AOB を調整する Speed と AOB を目標に合わせて調整する。 Historical モードではここが最重要。
  5. 5. 諸元入力を確定する 諸元入力 を押し、その時点の TDC 解を発射シーケンスへ反映する。
  6. 6. 発射深度を合わせる 発射可能深度は 10m - 20m。基本は 15m を維持する。
  7. 7. 発射準備を行う 発射準備 を押す。潜航中は 注水 → 均圧 → 外扉開放、 浮上中は短縮手順で進む。進行は Firing Sequence で確認する。
  8. 8. 発射する 条件が揃ったら 発射 を実行する。発射後は魚雷走行、命中判定、 排水・再整列へ進む。

命中率を上げるコツ

やるべきこと

  • 潜望鏡で視認して測距する
  • TDC の Speed / AOB を雑に入れない
  • 深度 15m 前後を安定維持する
  • 発射準備完了を待ってから撃つ

避けるべきこと

  • 受動聴音だけで即射する
  • 深度 60m などで撃とうとする
  • TDC が範囲外のまま強行する
  • 護衛艦に接近されてから慌てて準備する

最短の実戦フロー

  1. ソナーで方位捕捉
  2. 艦長席で潜望鏡視認と距離測定
  3. 雷撃席で TDC 方位・距離同期、Speed / AOB 調整
  4. 諸元入力
  5. 航海長席で 15m 前後維持
  6. 発射準備完了待ち
  7. 発射
