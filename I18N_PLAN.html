SilentDepth Internationalization Plan

SilentDepth 多言語化実装計画

SilentDepth を海外プレイヤーにも公開できるようにするための実装計画。 まずは 日本語 / English の2言語対応を対象にし、UI・HUD・ログ・マニュアルを段階的に切り替えられる状態を作る。

最初の目標は 遊べる入口 を英語化すること

基本方針

  • 日本語UIを削るのではなく、JP / EN 切替式にする
  • 物理計算や戦闘ロジックは変えず、文言分離を先に進める
  • ドイツ語復唱は演出として維持し、意味説明だけ日本語 / 英語で切り替える
  • index.html と manual/ を最優先で多言語化する

到達目標

Phase A

ヘッダー、役職名、主要ボタン、HUD見出しが JP / EN で切り替わる。

対応実装: Phase 1-2

Phase B

Duty Board、主要報告文、Campaign Status を含むゲーム主要導線が英語でも成立する。

対応実装: Phase 3-4

Phase C

manual/ 一式と Bridge Log まで含めて、多言語版公開が成立する。

対応実装: Phase 5-6

多言語化方針

文言の分離

index.html と script.js に直書きされている文言を、言語辞書から描画する構造へ移す。

切替UI

ヘッダー Control に JP / EN を置き、設定は localStorage に保持する。

英語表現

直訳ではなく、海外プレイヤーに通じる海戦ゲーム用語へ寄せる。

ドイツ語復唱

音声はドイツ語のままでよい。意味説明のグロスだけ日本語 / 英語切替にする。

推奨: 最初から i18n.js 分離で始める。

レイアウト対応とフォールバック

CSS 方針

  • ヘッダー帯は英語長文化を見越して折返し許可
  • 右サイドのボタンは font-size: clamp() と min-width 再調整で対応
  • 長い英語ラベルは短縮形も検討する

辞書キー欠落時

初期実装では 日本語へフォールバック を採用する。キーそのものの表示はデバッグ時のみ許可する。
